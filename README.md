
# Minha Rotina Acessível

## Sobre o projeto

O projeto Minha Rotina Acessível foi desenvolvido utilizando HTML5 e CSS3.

O objetivo é apresentar uma rotina diária de maneira simples, organizada e previsível, ajudando as pessoas a compreenderem suas atividades do dia a dia.

A página apresenta três informações principais:

- O que fazer.
- Quando fazer.
- Onde fazer.

## Atividades da rotina

O site apresenta as seguintes atividades:

1. Acordar.
2. Tomar café da manhã.
3. Estudar.
4. Almoçar.
5. Fazer atividades de lazer.
6. Jantar.
7. Preparar para dormir.

## Recursos utilizados

- HTML5.
- CSS3.
- GitHub.
- GitHub Pages.

## Acessibilidade

Foram utilizadas boas práticas de acessibilidade:

- Linguagem simples e objetiva.
- Títulos organizados.
- Cores suaves.
- Bom contraste entre texto e fundo.
- Informações separadas por seções.
- Horários destacados.
- Navegação simples.
- Layout adaptável para celulares.
- Foco visível para navegação pelo teclado.
- Respeito à preferência por movimento reduzido.

## Reflexão

**Como uma interface organizada e previsível pode melhorar a experiência de navegação de uma pessoa autista?**

Uma interface organizada e previsível pode ajudar uma pessoa autista a compreender melhor as informações e realizar suas atividades com mais tranquilidade.

Quando os horários, locais e tarefas estão apresentados de maneira clara, fica mais fácil entender o que precisa ser feito e qual será a próxima atividade.

Além disso, uma página com poucas cores, textos objetivos e informações bem organizadas pode diminuir distrações e facilitar a navegação.

Assim, a acessibilidade contribui para uma experiência mais confortável, independente e inclusiva.
